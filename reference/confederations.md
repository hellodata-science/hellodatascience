# FIFA Confederations Data

The data was obtained from FIFA website
<https://inside.fifa.com/associations/> and contains information on the
FIFA Member Associations (MAs), also known are confederations, which are
responsible for the development and governance of football/soccer within
their region

## Usage

``` r
confederations
```

## Format

A data frame with 7 rows and 2 variables. Each row represents a FIFA
confederation, including FIFA itself.

- confederation:

  name of the FIFA member association

- region:

  region or continent overseed by the confederation

## Source

(2026). <https://inside.fifa.com/associations/>.
